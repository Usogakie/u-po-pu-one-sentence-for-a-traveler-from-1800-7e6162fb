One sentence for a traveler from 1800: the internet is a single
post office where your letter reaches the far side of the world
before your tea goes cold, and the reply is already on its way back.
Built only from things a person from 1800 already knows — no word coined
after their time except the thing itself.

## Run it

```sh
python3 main.py
```

The program writes exactly one sentence (157 characters, no trailing
newline) to `${MAKEFUN_OUTPUT_DIR:-/output}/entry.txt` and nothing else.
